# devdeck-site

Public site for [Devdeck](https://devdeck.sh) — landing page plus the Sparkle
appcast feed.

Deployed to [Cloudflare Pages](https://pages.cloudflare.com) on every push to
`main` and served from `https://devdeck.sh`.

| File | Purpose |
|---|---|
| `index.html` | Landing page, links to GitHub Releases |
| `appcast.xml` | Sparkle 2 appcast (regenerated by `scripts/release.sh` in the private source repo) |

Source code lives in a private repository. Release binaries (signed,
notarized) are published to [`BoforDK/devdeck-releases`](https://github.com/BoforDK/devdeck-releases).
