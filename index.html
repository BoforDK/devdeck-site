Devdeck

An Xcode-style workspace for AI coding agents on macOS.
Git worktrees, terminals, diffs, and Claude Code sessions in one window.

Download for macOS All releases →

Requires macOS 15 (Sequoia) or later. Apple silicon & Intel.

What's inside

  • Worktree-first git workflowSpin up an isolated worktree per task, switch between them like Xcode schemes.
  • Three-pane shellProjects sidebar, content workspace (terminals / diffs / browser / agents), inspector.
  • Persistent terminalsSessions survive app restarts via an out-of-process daemon.
  • Zero-config agent integrationClaude Code runs in any tab; status streams back to the app as native notifications.
